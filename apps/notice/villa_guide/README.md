# 남광쉐르빌 관리 만화 PWA

9페이지 관리 만화 뷰어입니다. 핀치 확대 상태에서는 현재 이미지를 이동하며, 원래 배율에서는 좌우 스와이프로 페이지를 넘깁니다.

## 실행 및 설치

이 폴더의 `index.html`, `pwa.js`, `sw.js`, `manifest.webmanifest`, `icons/`를 함께 HTTPS 서버에 배포합니다. GitHub Pages의 하위 폴더에서도 상대 경로로 동작합니다.

로컬 확인:

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

`http://127.0.0.1:4173/`에 접속합니다. 지원 브라우저의 설치 메뉴를 사용하거나 iPhone/iPad의 Safari에서 공유 → 홈 화면에 추가를 선택합니다. HTML 파일을 직접 열면 기존 뷰어는 사용할 수 있지만 PWA 설치와 서비스 워커는 사용할 수 없습니다.

## 오프라인 및 업데이트

- 처음 온라인으로 열면 약 11 MiB의 HTML과 아이콘·앱 파일을 캐시합니다. 저장을 완료한 뒤에는 오프라인에서도 모든 만화를 읽을 수 있습니다.
- 마지막 페이지 번호는 기존처럼 `localStorage`에 저장합니다. 브라우저의 사이트 데이터 삭제 시 캐시와 읽기 기록이 제거될 수 있습니다.
- 배포 파일이 바뀌면 `sw.js`의 `VERSION`도 올립니다. 모든 파일을 배포한 후 서비스 워커를 배포하세요.
- 새 버전은 전체 파일의 캐시에 성공해야 설치됩니다. 기존 앱의 모든 탭과 창을 닫고 다시 열면 준비된 업데이트가 적용됩니다. 읽는 중 강제로 새로고침하지 않습니다.
- 캐시 정리는 이 앱의 배포 경로에 속한 이전 버전에만 적용됩니다.

## 확인 항목

HTTPS 또는 localhost에서 설치, 최초 캐시 완료 후 네트워크를 끈 상태의 재실행, 9페이지 열람, 확대 상태 이동, 배율 복원 후 스와이프, 마지막 페이지 복원을 확인합니다. 실제 모바일 홈 화면 설치는 기기에서 확인해야 합니다.
